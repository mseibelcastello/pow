3) Explique cómo se incluye un IFRAME en una página web y que sucede cuando accionamos los enlaces que están dentro de la información del frame.
Un iframe (inline frame) permite incrustar otra página HTML dentro de una página web.
	<iframe src="pagina.html" width="600" height="400"></iframe>
La página principal sigue siendo la misma, pero dentro de ella aparece una ventana que muestra el contenido de otra página.
Cuando hacemos clic en un enlace que está dentro del iframe, por defecto, la nueva página se carga dentro del mismo iframe, mientras que la página principal permanece sin cambios.

4) ¿Qué es una imagen SVG? ¿Las imágenes SVG son compatibles con todos los navegadores? ¿Qué puede utilizar en una imagen SVG?
Es un formato de imagen vectorial. A diferencia de una imagen rasterizada como JPG o PNG, una SVG está definida mediante elementos geométricos y texto, por lo que puede escalarse a distintos tamaños sin perder calidad.
A diferencia de una imagen rasterizada como JPG o PNG, una SVG está definida mediante elementos geométricos y texto, por lo que puede escalarse a distintos tamaños sin perder calidad.
En una imagen SVG se pueden utilizar elementos como <circle>, <rect>, <line>, <ellipse>, <polygon>, <path> y <text>.

5) Indague cuales son los ventajas y desventajas de utilizar imágenes SVG. ¿En qué casos utilizaría una imagen SVG?    
Ventajas de SVG
No pierde calidad al escalar: al ser vectorial, podés agrandar o achicar la imagen sin que se pixele.
Suele ocupar poco espacio: especialmente en gráficos simples, íconos y logos.
Se puede modificar con CSS: podés cambiar colores, bordes, tamaños, etc.
Se puede manipular con JavaScript: permite crear gráficos interactivos o animados.
Es editable: al estar basado en XML, su contenido puede modificarse directamente mediante código.
Es ideal para gráficos simples: logos, íconos, diagramas, gráficos estadísticos, etc.
Permite animaciones: SVG tiene herramientas para animar sus elementos.
❌ Desventajas de SVG
No es ideal para fotografías: una fotografía tiene muchísimos detalles y sería poco práctico representarla mediante vectores.
Puede volverse pesado: un SVG con una enorme cantidad de elementos y detalles puede tener un archivo muy grande y ser más costoso de procesar.
Tiene mayor complejidad: para gráficos muy elaborados puede ser más difícil trabajar con SVG que con una imagen rasterizada.
Puede requerir conocimientos de XML/CSS/JavaScript si queremos modificarlo o hacerlo interactivo.
Puede presentar diferencias en funciones muy específicas dependiendo del navegador o de cómo se haya generado el SVG, aunque el soporte general actual es muy bueno.
usaría SVG principalmente cuando necesito que una imagen mantenga su calidad independientemente del tamaño.

Por ejemplo:

Logos de empresas.
Íconos de una página web.
Botones y elementos gráficos de una interfaz.
